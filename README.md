# Credit Card Payment System

A backend application for managing masked credit cards, processing simulated payments, and maintaining transaction history.

## Tech Stack

- Python 3.12
- Django
- Django REST Framework
- FastAPI
- MySQL
- JWT Authentication
- Pydantic
- Postman
- Swagger / OpenAPI
- Git & GitHub
